# katuxos · Desarrollo Artesanal

## 🛠️ Módulos desarrollados para Prestashop

- Recargo de equivalencia en checkout y factura (por grupo)
- Carga de stock para combinaciones desde Excel
- Integración de pago con Addi
- Visualización de videos de Vimeo en ficha de producto
- Reloj cuenta atrás en homepage
- Sistema de sincronización multitienda:
  - Exportación desde tienda master
  - Actualización de productos, stock y precio en tiendas hijas
  - Cargas programadas por cron
  - Envío de pedidos a tienda master (dropshipping)
- Popup en checkout para OnePageCheckout
- Carrusel de productos cuando falta monto para envío gratuito
- Limpieza de base de datos
- Asignación automática de combinación por defecto sin stock
- Reseñas con IQITReviews + panel propio en Symfony
- Pago con reserva (adaptación de ps_wirepayment)
- Adaptación de módulo gratuito de WhatsApp para versión 8.x
- Adaptación de módulo captcha gratuito para versión 8.x

## 🔌 Plugins desarrollados para WordPress

- Formulario de adhesión personalizado
- Filtros para tipos de entrada personalizados
- Escritorio de gestión de adheridos con:
  - Flujo de avisos por email
  - Gráficas por edad, zona, etc.

## 📱 Webapps y apps móviles

- Webapp Symfony para control horario
- App móvil en Ionic/Angular para registro de visitas de vendedores a clientes:
  - Envío de datos vía API a backend Symfony
  - Niveles de acceso, configuración y visualización por equipo de ventas
